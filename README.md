## 🗄️ قاعدة البيانات (Tables API)

| الجدول | الوصف | الحقول الرئيسية |
|--------|-------|----------------|
| `products` | المنتجات | name, category, price, unit, stock, is_new, discount |
| `orders` | الطلبات | customer_name, phone, items(JSON), total, status |
| `customers` | العملاء | name, phone, balance, is_member |
| `offers` | العروض | title, description, discount_percent, is_active, type |
| `chat_messages` | رسائل الدردشة | sender_name, message, is_admin |

## ✅ جاهزية النشر على GitHub و Render

تم تجهيز المشروع ليعمل مباشرة على Render كخدمة **Node Web Service** بدل الاعتماد على واجهة `tables/` غير الموجودة داخل الاستضافة الثابتة.

### الملفات المضافة للنشر:
- `server.js` — خادم Express لتشغيل الموقع والـ API محلياً وعلى Render
- `package.json` — تعريف المشروع وأوامر التشغيل
- `render.yaml` — إعداد افتراضي مناسب للنشر على Render
- `data/db.json` — بيانات أولية قابلة للتعديل من لوحة الإدارة
- `assets/logo.png` و `assets/favicon.png` — الشعار وأيقونة الموقع
- `.gitignore`

### التشغيل المحلي:
```bash
npm install
npm start
```
ثم افتح:
```text
http://localhost:3000
```

### ملاحظات مهمة قبل النشر الفعلي:
- البيانات حالياً محفوظة في ملف JSON داخل `data/db.json`
- في Render على الخطة المجانية قد يتم فقدان التعديلات بعد إعادة البناء أو إعادة التشغيل
- لو تريد حفظ دائم للطلبات والمنتجات، الخطوة التالية الأفضل هي ربط قاعدة بيانات حقيقية مثل PostgreSQL أو Supabase
