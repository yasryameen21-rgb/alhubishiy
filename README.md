# محلات الحبيشي - النسخة المطورة

تم تحويل المشروع إلى نسخة Full Stack جاهزة للنشر على Render أو أي استضافة Node.js.

## أهم الإضافات
- باكند Node.js + Express
- قاعدة بيانات SQLite محلية تحفظ الطلبات والعملاء والعضويات والإدارة والمصادر الرياضية
- إشعار البريد عند وصول طلب جديد عبر SMTP
- تسجيل دخول للوحة الإدارة بالبريد وكلمة المرور مع حفظها في القاعدة
- تسجيل عضوية للزوار والعملاء من داخل الموقع
- صفحة أخبار رياضية `sports.html`
- إدارة مصادر RSS الرياضية من داخل لوحة الإدارة
- نسخ ومشاركة رابط الموقع من لوحة الإدارة
- تحسينات SEO لظهور الاسم العربي `محلات الحبيشي` والاسم الإنجليزي `Alhabeshi Stores`
- تحديث صفحة نبذة عن المحل من أكثر من 200 صنف إلى أكثر من 1500 صنف

## الملفات الجديدة المهمة
- `server.js` الباكند الرئيسي
- `package.json` الحزم والأوامر
- `.env.example` متغيرات البيئة المطلوبة
- `sports.html` صفحة الأخبار الرياضية
- `render.yaml` إعداد سريع لـ Render
- `sitemap.xml` و `robots.txt` لتحسين الأرشفة

## التشغيل محلياً
```bash
npm install
cp .env.example .env
npm start
```
ثم افتح:
- `/` الصفحة الرئيسية
- `/admin.html` لوحة الإدارة
- `/sports.html` صفحة الرياضة

## متغيرات البيئة المطلوبة
انسخ القيم من `.env.example` واضبطها:
- `OWNER_EMAIL`
- `JWT_SECRET`
- `SMTP_HOST`
- `SMTP_PORT`
- `SMTP_SECURE`
- `SMTP_USER`
- `SMTP_PASS`
- `SMTP_FROM`
- `BASE_URL`

## إعداد بريد Gmail على Render
لو ستستخدم Gmail:
1. فعّل التحقق بخطوتين لحساب Gmail
2. أنشئ App Password
3. ضع البريد في `SMTP_USER`
4. ضع App Password في `SMTP_PASS`
5. ضع بريدك في `OWNER_EMAIL`

## ملاحظات النشر
- أول دخول إلى `admin.html` سيطلب إنشاء حساب الإدارة لأول مرة
- بعد إنشاء الحساب سيتم حفظه في القاعدة
- ملف `data/alhabeshi.sqlite` يُنشأ تلقائياً أثناء التشغيل
- بعد معرفة رابط Render النهائي استبدل `example.com` داخل:
  - `sitemap.xml`
  - `robots.txt`
  - الروابط canonical داخل الصفحات إن رغبت
